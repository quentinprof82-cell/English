# Improve My English 🇬🇧

V1 d'une PWA d'apprentissage de l'anglais.

## Modules
- ⭐ Essential 100
- 🏠 Vie quotidienne
- 🛒 Commerce & vente
- 💰 Économie & finance

## Fonctionnalités V1
- Sessions de 10 questions
- QCM avec correction immédiate
- Exemple en contexte
- Progression locale avec `localStorage`
- Session recommandée
- Révisions
- Statistiques
- Interface responsive
- Navigation mobile en bas de l'écran
- Gros textes et grandes zones tactiles pour iPhone
- PWA installable

## Mise en ligne avec GitHub Pages
1. Créer un dépôt GitHub, par exemple `improve-my-english`.
2. Déposer tous les fichiers de ce dossier à la racine du dépôt.
3. Aller dans **Settings → Pages**.
4. Choisir **Deploy from a branch**.
5. Sélectionner la branche `main` et le dossier `/root`.
6. Enregistrer.
7. Ouvrir l'adresse GitHub Pages sur l'iPhone.
8. Dans Safari : **Partager → Sur l’écran d’accueil**.

## Important pour l'iPhone
L'interface bascule automatiquement en mode mobile :
- barre de navigation fixe en bas, compatible avec l'encoche et la zone Home Indicator ;
- boutons larges ;
- texte de base 17–18 px ;
- mots et titres volontairement grands ;
- réponses QCM sur une colonne ;
- aucun menu horizontal qui déborde de l'écran.

## Données
La progression est actuellement stockée dans le navigateur via `localStorage`. Elle n'est donc pas synchronisée entre appareils.
